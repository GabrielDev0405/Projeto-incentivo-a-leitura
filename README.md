Projeto de incentivo a leitura

Desenvolvi este site funcional como parte de uma avaliação da matéria de desenvolvimento web na faculdade
o site serve como um informativo sobre o desaparecimento da leitura e maneiras de incentivar principalmente os jovens a criarem o
hábito de ler.

O projeto utiliza conhecimentos de HTML5 CCS3 e JavaScript para criar uma interface frontend e funcionalidades pelo backend
tendo em vista que não tive como aprofundar meus conhecimentos em JavaScript utilizei da ferramenta de IA Claude para me auxiliar na 
construção do script do site, o qual atribui funcionalidades extras para o formulário do final como criar um perfil de leitor para o usuario
